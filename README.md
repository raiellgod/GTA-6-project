# GTA 6 — Fan Landing Page

Landing page temática inspirada em **Grand Theft Auto VI**, criada como estudo de front-end com foco em apresentação visual, animações e experiência de navegação.

## Objetivo

Explorar uma landing page mais cinematográfica e dinâmica, combinando HTML, CSS, JavaScript e animações acionadas durante a navegação.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger

## Destaques

- Animações com GSAP
- Efeitos acionados pelo scroll com ScrollTrigger
- Navegação temática
- Seção inspirada em Vice City
- Área dedicada ao trailer
- Organização separada de assets, estilos e scripts

## Estrutura

```text
.
├── assets/
├── css/
├── js/
└── index.html
```

## Aprendizados

O projeto foi utilizado para praticar:

- animações orientadas à experiência do usuário;
- controle de timeline com GSAP;
- efeitos vinculados ao scroll;
- organização de arquivos front-end;
- criação de uma identidade visual baseada em uma referência forte.
